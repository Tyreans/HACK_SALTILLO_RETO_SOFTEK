# Models & Data Layer (`backend/src/models/`)

## Purpose
This folder contains the data access layer representing the PostgreSQL database entities, query methods, and database schemas.

## Responsibilities
- Define database entity structures, relationships, and constraints.
- Execute parameterized SQL queries or ORM/query-builder methods against PostgreSQL.
- Prevent SQL injection: Always use parameterized queries (e.g. `client.query('SELECT * FROM users WHERE id = $1', [id])`) and avoid raw string interpolation.

## Example Models
- `user.model.js`: PostgreSQL queries for user accounts, credentials, and roles.
- `session.model.js`: Database queries for active sessions or refresh tokens.
- `chatHistory.model.js`: PostgreSQL queries for storing conversations, user prompts, and responses generated by Gemini API.
