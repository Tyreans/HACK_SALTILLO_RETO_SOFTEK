# Database Root (`backend/db/`)

## Purpose
This directory contains PostgreSQL database migration scripts, initial seed fixtures, and SQL utility scripts.

## Subdirectories
- [`migrations/`](file:///home/tyreans/hacktec/backend/db/migrations/README.md): Version-controlled SQL or ORM schema migration files.
- [`seeds/`](file:///home/tyreans/hacktec/backend/db/seeds/README.md): Seed scripts for populating development and testing databases with baseline records.
