# Documentation Directory (`docs/`)

## Purpose
This directory houses all technical and functional documentation for the project, providing guides for developers, architects, and stakeholders.

## Subdirectories
- [`architecture/`](file:///home/tyreans/hacktec/docs/architecture/README.md): High-level system design, sequence diagrams, component architecture, and integration flows (including Gemini AI backend flow).
- [`api/`](file:///home/tyreans/hacktec/docs/api/README.md): API contract definitions, REST endpoint documentation, request/response schemas, and status codes.
- [`database/`](file:///home/tyreans/hacktec/docs/database/README.md): PostgreSQL schema designs, entity-relationship diagrams (ERDs), data dictionaries, and migration strategies.
- [`setup/`](file:///home/tyreans/hacktec/docs/setup/README.md): Developer onboarding guides, prerequisite installation, local environment configuration, and execution instructions.
