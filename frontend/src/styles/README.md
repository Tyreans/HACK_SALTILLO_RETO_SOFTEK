# Styling & Design Tokens (`frontend/src/styles/`)

## Purpose
This directory contains global styles, CSS utility classes, design tokens, and CSS reset rules for the application.

## Contents
- `index.css` or `globals.css`: Base CSS reset, typography setups, and root CSS variables (colors, fonts, spacing).
- `variables.css`: Design tokens for light and dark themes.
- Tailwind CSS directives or SCSS module mixes (depending on the styling library chosen).

## Conventions
- Prefer modular styles, CSS variables, or utility classes over unbounded generic class names to avoid cross-page CSS pollution.
