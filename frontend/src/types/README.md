# Types & Interfaces (`frontend/src/types/`)

## Purpose
This directory contains TypeScript type definitions, interface contracts, or JSDoc typedef definitions shared across the frontend codebase.

## Typical Type Definitions
- `user.types.ts`: User profile shape, authentication state, and role types.
- `gemini.types.ts`: Prompt payload formats, response message structures, and streaming chunk types.
- `api.types.ts`: Generic API response envelopes (`ApiResponse<T>`, pagination metadata, error formats).
- `navigation.types.ts`: Route param types and navigation link definitions.
